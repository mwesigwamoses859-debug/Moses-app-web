Common questions

Before you book.

Can you help with both laptops and desktops?

Yes. Describe the make, model and problem so we can confirm the support required and any parts or specialist work involved.

Will my files be kept?

Discuss your files and backup plan before work starts. Some faults or repairs can affect data, so do not assume that a reset, reinstall or storage repair will preserve it.

Can you solve the problem remotely?

Some setup and software issues can be guided remotely. Send the symptoms first so we can decide whether remote support is suitable or an appointment is needed.
